# ISO 15118 图片目录

用于归档 ISO 15118 / DC V2H 主题的系统架构图、通信时序图和后续标准对照图。

## 已归档图片

- `dc-v2h-architecture.png`：DC V2H 系统架构概念图
- `dc-v2h-sequence.png`：DC V2H 通信时序概念图

两张 PNG 已按以下文件名归档；上级 `ISO15118.md` 已添加相对路径引用。

## 归档要求

- AI 生成图必须标注为概念示意图，不得作为标准原图或实测证据。
- 正式时序和规范性结论需核对项目适用标准版本及条款。
- 文件名使用小写英文和连字符；Markdown 图片路径区分大小写。
- 上传前检查图片中是否含有敏感信息。

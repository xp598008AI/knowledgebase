## 技术图片自动归档

在本地克隆仓库后，执行：

`python scripts/import_knowledge_image.py <图片文件> <目标Markdown相对路径> --title "图片标题"`

脚本会将图片复制到目标文档旁的 `images/` 目录，并插入 Markdown 图片引用和审核提示。审核后提交并推送；GitHub Actions 会检查本地图片引用和 Markdown 文件链接。请勿将 AI 生成图片未经核实直接作为标准要求或实测证据。

## 技术图片归档：优先 SVG 直写

流程图、系统架构图、状态机、时序图和技术知识卡片，优先生成 SVG 源码，通过 GitHub 文件接口直接创建 `.svg` 文件，再在目标 Markdown 中插入相对路径引用。无需先下载到本地，也不需要 Base64 伪装上传。

- 单主题专用图：放在该主题文档旁的 `images/` 目录。
- 跨主题复用图：按 [技术图片资产库规范](06-创新、扩展与职业竞争/技术图片资产库/README.md) 管理，并从相关文档引用。
- 真实 PNG/JPG 等位图：必须使用真实图片文件字节，不能用 SVG 文本或图片 URL 冒充位图文件。
- 每次归档后检查：图片文件已存在、Markdown 相对引用正确、图示说明和审核状态完整。

本地图片文件仍可使用以下脚本导入：

`python scripts/import_knowledge_image.py <图片文件> <目标Markdown相对路径> --title "图片标题"`

脚本会将图片复制到目标文档旁的 `images/` 目录，并插入 Markdown 图片引用和审核提示。仓库中的 GitHub Actions 可检查本地图片引用和 Markdown 文件链接，但需以实际 Actions 运行记录为准；请勿将未经核实的 AI 生成图作为标准要求或实测证据。

# V2G 与 V2H：收益、系统方案及 EVCC 职责

> 状态：Draft｜版本：v1.0｜整理：2026-10-27｜主归属：充电系统｜标签：V2G、V2H、EVCC、ISO 15118-20、BPT、系统架构  
> 范围：以 CCS 体系和 DC 双向功率传输为重点，对比 AC 方案。本文为工程学习材料，公式均为示例；标准要求、功能安全等级、并网条件及接口参数需按项目版本、目标市场和正式资料复核。没有实际测试或认证证据。

## 1. 概念与边界

- **V2H**：车辆向家庭供能；可用于并网削峰，也可在具备离网能力和隔离设备时用于停电备电。
- **V2G**：车辆与电网互动，具备条件时向公共电网输出能量，或参与市场调度。
- **V2L**：车辆向外部独立负载供电；不等同于支持家庭配电或电网并网。
- **V1G**：调整充电时间或功率，通常不向外放电；也可以提供部分电网灵活性。
- AC/DC 是车与供电设备之间的功率接口；V2G/V2H 是应用场景。支持某一组合不意味着支持全部组合。
- EVCC 是车端通信与充放电协同功能，具体安全职责按整车架构分配；并网与离网隔离保护不能仅依赖 EVCC。

## 2. 收益与成本

| 项目 | V2H | V2G |
|---|---|---|
| 潜在收益 | 停电备电、峰谷套利、光伏自用 | 电价套利、需求响应、辅助服务 |
| 外部条件 | 家庭配电、双向设备、EMS；备电另需离网和隔离能力 | 并网许可、双向计量、市场规则、聚合及结算 |
| 约束 | 车辆在家时间、备用 SOC、负载峰值、安装成本 | 在线率、调度可用时间、功率/电量、结算与分成 |

停电备电示例：电池可用容量 80 kWh、当前 SOC 70%、保留 SOC 30%、电池至交流负载效率 90%，理论可用电量 = 80 × (0.70 − 0.30) × 0.90 = **28.8 kWh**。平均负载 1 kW 时约 28.8 小时。效率与 SOC 均为假设，实际还受功率、温度、辅助耗电、负载启动峰值和设备离网能力限制。

峰谷示例：输出至家庭 10 kWh，往返效率 85%，谷价 0.35 元/kWh、峰价 0.90 元/kWh，则直接购电 9.00 元，谷时补能 10/0.85×0.35≈4.12 元，毛节省约 4.88 元；若额外电池等成本假设为 0.15 元/输出 kWh，净节省约 3.38 元。数值并非实际地区电价或寿命结论；设备安装、折旧、资金成本仍未计入。

年净收益可分解为：电费节省 + 服务收入 + 备电价值 − 损耗和额外购电 − 电池寿命成本 − 设备安装维护与平台费用。光伏自用需同时扣除放弃的上网收益。电池寿命影响与温度、SOC、功率、循环和保修条件有关，不使用固定值作为普适结论。

聚合示例：1000 台车 × 在线允许调度比例 40% × 每车 5 kW = 2 MW；若每台实际允许输出 5 kWh，总可用能量约 2 MWh。功率、持续时间和响应可靠度应分别核算。

## 3. 系统方案与能量流

### 3.1 DC 双向

`动力电池/BMS ↔ 车辆 DC 接口 ↔ 双向 DC EVSE（SECC、功率变换）↔ 家庭配电/EMS ↔ 电网和家庭负载`

- 充电：电网交流 → 外部变换 → 车辆直流接口 → 电池。
- 放电：电池 → 车辆直流接口 → 外部双向变换 → 家庭或电网。
- 主要功率变换在外部设备；车载 OBC 不一定参与，但电池包、充电高压通路、接触器、测量、BMS、热管理和低压供电必须允许反向工况。
- 设备需覆盖车辆电压范围和功率能力；备电还需离网成网和家庭隔离切换。
- [已有 DC V2H 架构与时序图文笔记](协议与时序/ISO15118.md)：为概念图，消息及状态须按正式标准和系统设计核对。

### 3.2 AC 双向

`动力电池/BMS ↔ 车载双向 OBC ↔ AC 设备 ↔ 家庭配电/EMS ↔ 电网和家庭负载`

- 主要变换在车端 OBC；普通单向 OBC 不能默认通过软件升级实现反向供电。
- OBC 的并网/离网能力、热设计、EMC、保护责任，以及外部配电切换需按产品方案和目标市场确定。

| 项目 | AC 双向 | DC 双向 |
|---|---|---|
| 双向变换主要位置 | 车载 OBC | 外部双向设备 |
| 整车重点 | 双向 OBC、散热和控制 | 高压反向通路、BMS、高压及热管理 |
| 外部重点 | 保护、配电及控制，实际复杂度依方案而定 | 双向功率变换、保护及接口适配 |
| 成本 | 按车辆规模、设备规模和认证综合比较 | 同左，不可仅凭拓扑判断 |

### 3.3 并网与离网

并网 V2H：家庭 5 kW 负载、光伏 2 kW、车辆放电 3 kW 时，理想电网功率 5−2−3=0 kW。零反送需测量及动态控制，不能仅由目标值保证。

离网备电：检测电网失电 → 可靠隔离公共电网 → 具备成网能力的设备建立交流电压/频率 → 车辆供电 → 电网恢复后按条件切回。隔离、过载/短路、启动冲击、切换时间和恢复均需单独设计；并网设备不一定支持离网，具备备电功能也不等于 UPS 级无中断。光伏能否在停电时继续工作取决于逆变器及系统兼容性。

## 4. 系统职责与接口

| 功能 | 主要承担方（示例，项目须明确分配） | 与 EVCC 的接口重点 |
|---|---|---|
| 电池允许及限制 | BMS | SOC、电压、充放电许可、动态电流/功率限值、故障 |
| 车端协议与会话 | EVCC | PLC、ISO 15118-20、服务选择、状态与超时 |
| 整车模式/高压管理 | VCU/高压控制器等 | 驻车、电源模式、接触器请求与反馈、热管理 |
| 车载 AC 双向变换 | 双向 OBC | 功率能力、方向、故障、温度、运行状态 |
| 外部协议及功率变换 | SECC、双向功率设备 | 能力、目标、运行状态、故障、功率停机 |
| 家庭调度 | 家庭 EMS | 电表、光伏、负载与策略；不一定直接与 EVCC 通信 |
| 并网/离网保护 | 依据系统架构由合规设备承担 | 保护和隔离状态影响会话；不能仅依赖通信 |
| 运营、计量与结算 | 平台、聚合商、计量系统 | 用户授权和业务边界由产品定义 |

EVCC 有时只能看到双向 EVSE 和充放电要求，并不必然知道输出电最终由家庭使用还是馈入电网。站端到平台可采用 OCPP 等接口；OCPP 2.1 支持 ISO 15118-20 及双向充电功能，但项目协议由双方实现决定。

## 5. EVCC 需要做什么

1. **连接和协议**：CP、PLC/SLAC、网络连接、适用 TLS、安全会话、ISO 15118-20 协议协商与超时。既有 DIN 70121/ISO 15118-2 能力不等于支持 -20 BPT。
2. **服务选择**：确认 AC/DC BPT、双方控制模式和参数兼容；设备、车辆或用户不允许时遵循项目定义的普通充电或安全退出策略。
3. **用户意愿与出行**：获取放电许可、最低 SOC、目标 SOC、出发时间和功率约束；优化策略可位于车端、EMS 或云端，EVCC 负责分配给它的接口和协同。
4. **车辆边界**：接收 BMS 充放电许可、限值、SOC、故障、高压状态；校验信号有效性、更新时间和量纲，在限值变化时及时协调。
5. **高压协同**：确认车辆/设备就绪，协调上电、预充及运行许可；接触器、预充、绝缘及保护由项目分配责任，不假设 EVCC 直接执行。
6. **运行控制**：依据选定服务与控制模式交换能力、调度和状态；协调充电、待机、放电、功率调整及方向变化。
7. **停止和恢复**：处理用户停止、最低 SOC、BMS 撤销、断链、CP 异常、设备故障等；区别停止请求、实际电流下降、高压退出和会话结束。
8. **诊断与可观测性**：记录服务、限值、数据新鲜度、请求/反馈、停止原因与时间戳；避免记录不必要的敏感信息。
9. **长期运行**：协调热管理、DCDC、12 V 供电、休眠唤醒和故障后的低功耗恢复。

### 功率边界示例

电池电压 400 V、BMS 允许 50 A，则电池侧理论限值 20 kW；车辆其他部件 15 kW、设备 12 kW、用户 10 kW 时，若各值已折算到**同一测量边界**，上限为 min(20,15,12,10)=10 kW。实际还须检查电压、电流约束、效率、辅助耗电、瞬态和限值有效期。跨电池侧、DC 接口侧、AC 电表侧不能未经换算直接比较。

### 方向与状态

建议明确项目内功率正负方向及每个外部接口的转换规则，协议字段、BMS、功率设备、电表和日志不一定采用同一符号。方向切换应处理降功率、双方就绪、许可、过渡状态、超时与异常；是否允许同一会话内切换及标准消息顺序由适用规范、服务和控制模式决定。

概念状态：待连接 → 建链 → 能力协商 → 待机 → 充电/放电 → 待机或停止 → 会话结束；运行中可进入故障处理。此示意不等于标准状态机。

### 数据接口检查

| 信号 | 必须约定 |
|---|---|
| BMS 许可、最大电流/功率 | 方向、单位、刷新周期、超时、无效值、失效动作 |
| SOC、目标 SOC、出发时间 | 数据来源、精度、有效期、仲裁与用户修改 |
| 接触器及高压准备 | 请求与反馈、负责方、确认超时及故障处理 |
| 温度及降额 | 测量点、限制策略、恢复阈值 |
| 功率命令及实际值 | 测量边界、正负号、响应时间、滤波与误差 |
| 故障/停止原因 | 优先级、锁存、日志及恢复条件 |

## 6. DC 双向工程流程

以下仅为功能阶段示意，非逐消息规范时序：插枪与车辆条件检查 → PLC 建链和协议/安全通信 → 服务发现及 BPT 选择 → 用户和 BMS 许可 → 参数/调度交互 → 高压准备 → 充放电运行及动态限值更新 → 受控停止 → 实际功率下降与高压退出 → 会话结束。每一步的具体消息、触发条件、超时及错误处理必须对照项目标准基线。

## 7. 异常、安全与验证

| 测试场景 | 前置/激励 | 期望验证点（阈值按项目要求） |
|---|---|---|
| 能力不匹配 | 对端无匹配 BPT 服务 | 不进入不支持的放电，退出或按配置运行 |
| BMS 限值降额 | 运行中降低允许功率 | 请求/实际值按规定响应，不越过安全边界 |
| 数据失效 | BMS 关键限值超时或无效 | 触发规定降级/停止，记录原因 |
| 方向切换 | 充电切放电，或反向 | 满足双方许可、过渡状态与功率条件 |
| 通信中断 | 运行中断开 PLC 或让响应超时 | 在规定时间内执行安全动作并记录证据 |
| 最低 SOC | 放电至用户设置边界 | 按策略停止，考虑估算误差和恢复策略 |
| 设备失电 | 站端重启或电网故障 | 系统按职责安全退出，不假设自动离网 |
| 枪锁/接触器异常 | 注入反馈不一致 | 禁止非法状态迁移，按安全概念处理 |
| 长时间运行 | 多小时低功率、热与低压供电 | 验证温升、DCDC、12 V、休眠及恢复 |
| 并网/离网切换 | 模拟失电和恢复 | 证明隔离、供电切换及保护符合适用要求 |

以上为待制定的验证建议，不是已完成测试。测试需记录配置、标准版本、波形、时间戳、预期/实际和结论。ASIL 应依据车辆 HARA 确定；并网保护、离网隔离与功能安全是协同的系统问题。网络安全需覆盖非授权放电、TLS/证书生命周期、指令完整性、更新与日志；TLS、用户授权、商业结算和 PnC 不应混为一谈。

## 9. 快速复习

1. **V2H 一定能停电备电吗？** 不一定；需要离网成网、隔离和负载切换。
2. **支持 ISO 15118-2 或 -20 就一定支持双向吗？** 不一定；需双方匹配 BPT 服务、模式、硬件与安全条件。
3. **EVCC 决定所有高压安全动作吗？** 不一定；责任需由系统安全架构分配。
4. **10 kWh 电池输出等于 10 kWh 家庭交流用电吗？** 不一定；要定义测量边界并计入损耗。
5. **设备可以反向供电就可以卖电吗？** 不一定；仍受并网、计量、市场和合同约束。

# 04-充电系统与产品

充电系统、EVCC、OBC、DCDC、BMS、交流/直流充电桩、无线充电及通信协议。

## 子主题

详见本目录下的子目录。新建内容建议使用 [技术知识卡片模板](../templates/技术知识卡片模板.md)，并记录来源、版本和审核状态。

## 建议学习路径
1. 充电系统全景 → AC/DC充电链路与接口。
2. EVCC/SECC：CP/PP → PLC → DIN 70121/ISO 15118 → 状态机、诊断和互操作。
3. OBC/DCDC：拓扑 → 控制与保护 → 热设计 → 验证。
4. BMS与充电桩：充电协同、功率分配和安全边界。

## 跨领域关联
EVCC通信超时：定时器/任务调度（基础）→ 需求追溯（ASPICE）→ 协议状态机（产品）→ HIL故障注入（验证）。标准时序参数须核对具体版本和消息。

## 推荐主线
1. **系统层**：先理解交流/直流充电能量流、控制流和责任边界。
2. **通信层**：CP/PP → PLC/SLAC → DIN 70121 / ISO 15118 → EVCC/SECC 状态机。
3. **功率层**：OBC → DC/DC → 功率器件 → 磁性元件 → 控制环路 → 热与 EMC。
4. **电池层**：BMS 状态估计 → 允许充电边界 → 快充降额 → 高压安全协同。
5. **工程层**：ASPICE 追溯 → 功能安全/FMEA → HIL/DV/PV → 互操作 → 失效闭环。

## 跨领域知识链示例
**EVCC 通信超时**：任务/定时器 → 协议状态机 → BMS/VCU 接口 → 高压安全责任 → HIL 故障注入 → ASPICE 需求与测试追溯。

**OBC 效率问题**：拓扑与工作点 → MOSFET 开关/导通损耗 → 磁性损耗 → 热阻网络 → 控制策略 → 效率地图与热验证。

## 学习输出统一规则
新建技术内容优先使用 [高效技术学习卡片模板](../templates/高效技术学习卡片模板.md) 或工程专题模板。每篇至少回答：它解决什么问题、原理是什么、接口/波形/状态如何、关键参数如何计算、会怎样失效、如何验证、与哪些上下游知识关联。

标准、器件参数和测试结论必须记录版本、来源、边界条件和审核状态；跨主题内容只设置一个主归属，其余位置使用相对链接，避免复制形成多个版本。

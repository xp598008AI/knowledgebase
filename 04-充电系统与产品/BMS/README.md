# BMS 技术知识树与学习路线

> 状态：学习导航 / Draft。用于理解 BMS 与充电系统的接口和系统工程边界；具体阈值必须来自目标电芯体系、系统安全概念和项目标定。

## 一、BMS 在充电系统中的角色
BMS 负责感知电芯/电池包状态并给出允许的充放电边界，是充电功率请求和高压安全决策的重要输入。EVCC、VCU、OBC/充电桩与 BMS 的职责应通过接口和状态机明确，避免把通信控制与电池安全控制混为一体。

## 二、六层知识树
1. **采样与感知**：单体电压、包电压、电流、温度、绝缘及采样诊断。
2. **状态估计**：SOC、SOH、SOP；库仑积分、OCV 修正、模型/滤波方法及误差来源。
3. **均衡与热管理**：被动/主动均衡；温度一致性；加热、冷却和充电功率降额协同。
4. **高压与安全**：接触器、预充、HVIL、绝缘、过压/欠压、过流、过温和热失控风险。
5. **充电协同**：允许充电电压/电流/功率、目标 SOC、温度限制、快充降额及故障停止条件。
6. **验证与诊断**：传感器故障、漂移、断线、粘连、通信异常、边界工况、故障注入和安全机制覆盖。

## 三、问题驱动学习路线
先回答“测得准不准” → “估得准不准” → “允许多少功率” → “异常时谁做什么动作” → “EVCC/VCU 如何获得可信状态” → “如何通过 HIL/台架/整车验证”。

## 四、与 EVCC 的关键接口思维
- EVCC 关注车桩通信和充电会话；BMS 关注电池状态与安全边界。
- 充电电流/电压请求应具有明确的来源、刷新周期、新鲜度判断和失效替代策略。
- 通信丢失、数据超时、无效值和状态不一致必须进入系统级异常路径设计。
- 快充能力不是固定值，应考虑 SOC、温度、电芯压差、老化状态和系统热能力等条件。

## 五、掌握标准
能够解释 SOC/SOH/SOP 的差异；画出充电协同信号链；说明接触器/预充的基本逻辑和责任边界；针对采样漂移、温度异常、通信超时设计故障响应；建立 BMS—EVCC—VCU—充电设备的系统级验证场景。

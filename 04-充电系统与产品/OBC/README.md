# OBC 技术知识树与学习路线

> 状态：学习导航 / Draft。面向车载充电机系统设计、软件控制和工程验证；具体参数以目标车型、电网制式、器件数据手册和项目需求为准。

## 一、先建立系统全景
OBC 将交流电网能量变换为动力电池所需直流能量，典型链路为：AC 输入与保护 → EMI/EMC 滤波 → PFC → DC Link → 隔离 DC/DC → 输出滤波与采样 → 高压电池。双向 OBC 还需覆盖反向功率流、并网控制及相关安全边界。

## 二、六层知识树
1. **输入与保护**：单相/三相输入、浪涌、预充、继电器/接触器、EMI 滤波、绝缘与接地。
2. **PFC 功率级**：Boost、Totem-Pole 等拓扑；功率因数、THD、母线电压、软开关及器件应力。
3. **隔离 DC/DC**：LLC、CLLC、DAB 等；变比、谐振网络、软开关、双向能力和宽电压范围。
4. **控制与软件**：电压环、电流环、前馈、限功率、启动/停机状态机、采样校准、PWM 与保护联动。
5. **热/器件/EMC**：Si/SiC/GaN 选型，磁性元件、电容寿命、损耗分解、冷却、共模/差模噪声。
6. **验证与安全**：效率、功率因数、THD、绝缘、耐压、热循环、EMC、异常输入、输出短路和故障降额。

## 三、问题驱动学习路径
| 阶段 | 核心问题 | 学习输出 |
|---|---|---|
| 1 | OBC 的能量如何从电网流到电池？ | 功率链路框图与能量流图 |
| 2 | PFC 为什么能改善 PF/THD？ | 电感电流波形与控制框图 |
| 3 | 隔离 DC/DC 如何实现变压、隔离与软开关？ | 拓扑对比与关键波形 |
| 4 | 电压环/电流环如何配合？ | 控制框图、带宽与保护边界 |
| 5 | 损耗和温升从哪里来？ | MOSFET/磁性件/电容损耗预算 |
| 6 | 如何证明设计可靠？ | DV/PV 验证矩阵与故障注入清单 |

## 四、工程学习重点
- 所有计算必须带输入电压、输出电压、功率、开关频率、温度和器件版本等边界条件。
- 将“拓扑原理”“控制算法”“器件选型”“热设计”“EMC”“验证”串成同一条证据链，而不是孤立学习。
- 对效率问题采用损耗分解：导通损耗、开关损耗、磁性损耗、电容 ESR、驱动及辅助电源。
- 双向 OBC/V2X 内容单独标明功率方向、并网要求和标准/法规版本。

## 五、掌握标准
能够独立画出 OBC 功率链路；解释 PFC 和隔离 DC/DC 关键波形；完成一个额定工况损耗估算；说明主要保护路径；针对效率、热、EMC 和异常工况设计验证用例。

## 六、学习方法
每个知识点使用 [高效技术学习卡片模板](../../知识库管理/templates/高效技术学习卡片模板.md)，至少包含：原理图/波形、一个数值计算、器件或控制参数、典型失效、验证方法和主动回忆题。技术参数必须关联数据手册、设计计算或实测证据。

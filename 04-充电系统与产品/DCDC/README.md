# DC/DC 技术知识树与学习路线

> 状态：学习导航 / Draft。覆盖车载高压/低压 DC/DC 及隔离型功率变换的通用学习框架，具体设计参数以项目输入输出范围和安全要求为准。

## 一、系统目标
DC/DC 的核心任务是把一个直流电压域稳定、高效、安全地转换到另一个直流电压域。工程上不仅看“能不能变压”，还要同时解决效率、动态响应、隔离、热、EMC、器件应力和故障保护。

## 二、六层知识树
1. **拓扑基础**：Buck、Boost、Buck-Boost；半桥/全桥；LLC/CLLC、PSFB、DAB 等隔离拓扑。
2. **功率器件与驱动**：MOSFET/SiC/GaN、体二极管、死区、栅极驱动、dv/dt、di/dt 与寄生参数。
3. **磁性与储能元件**：电感、变压器、电容；纹波、饱和、铜损/铁损、漏感和温升。
4. **闭环控制**：电压环、电流环、峰值/平均电流控制、前馈、补偿网络、稳定性与瞬态响应。
5. **保护与热设计**：OVP/OCP/UVP/OTP、短路、软启动、降额、损耗预算和冷却路径。
6. **验证与量产**：效率地图、纹波、动态负载、EMC、热循环、器件容差、异常工况与寿命验证。

## 三、推荐学习顺序
Buck/Boost 基础 → PWM 与电感伏秒平衡 → 连续/断续模式 → MOSFET 开关损耗 → 电压/电流闭环 → 隔离拓扑 → 磁性元件 → 软开关 → 热与 EMC → DV/PV。

## 四、必须会做的工程计算
- Buck 理想连续模式：`D ≈ Vout / Vin`，实际设计再加入器件压降、死区和控制余量。
- 电感纹波：根据拓扑、Vin/Vout、L、fsw 和占空比计算，并检查峰值电流与饱和裕量。
- MOSFET 损耗：至少拆分导通、开关、驱动及反向恢复相关损耗。
- 热设计：由总损耗、热阻网络和冷却边界估算结温，并用实测校核。

## 五、常见踩坑
只看典型 RDS(on) 不看温度；忽略寄生电感造成尖峰；环路带宽与采样/PWM 延迟不匹配；磁性元件只算电感量不校核饱和和损耗；效率只测额定点而没有效率地图；保护阈值未考虑测量误差和器件容差。

## 六、掌握标准
能从规格定义出发选择拓扑；完成关键器件初选和一阶计算；画出功率级关键波形；解释闭环稳定性与瞬态；建立损耗/热预算；设计正常、边界和故障验证矩阵。

# EVCC 技术知识树与学习路线

> 状态：学习导航 / Draft。适用 CCS1/CCS2 交流与直流充电，具体实现须区分地区法规、车型平台和 ISO 15118 / DIN 70121 版本。

## 一、系统全景（先回答 EVCC 负责什么）

EVCC 是车端充电通信控制功能，协调充电口硬件、导引检测、PLC 高层通信、整车充电状态、BMS/VCU/OBC 与诊断。**EVCC 不等于整车高压安全控制器**：接触器控制、绝缘监测和电池保护的职责需按系统架构明确。

## 二、六层知识树

1. **接口与物理层**：CCS1/CCS2 接口；CP、PP；PWM 与低频导引；PLC 耦合与 SLAC；唤醒/休眠及插拔枪边界。
2. **协议层**：DIN SPEC 70121、ISO 15118-2、ISO 15118-20；协议协商、会话建立、服务发现、参数协商、功率传输、会话结束；TLS 与证书/PnC（按版本与配置区分）。
3. **应用与状态机**：充电准备、启动、运行、停止、故障恢复；交流/直流差异；超时、重试、幂等性、异常退出。
4. **车内协同**：EVCC 与 BMS、VCU、OBC、热管理、充电口执行器之间的信号、权限、状态新鲜度与降级策略。
5. **软件工程**：BSW/驱动、通信栈、协议适配、业务状态机、诊断、日志、配置、OTA；任务调度、资源占用与可观测性。
6. **验证与质量**：一致性、互操作、HIL 故障注入、网络异常、断电恢复、温度/电流限制、功能安全分析与 ASPICE 证据追溯。

## 四、工程案例：直流充电通信超时

**场景**：充电会话进行中，EVCC 在规定的等待窗口内未收到预期响应。实际窗口由所选协议版本、消息类型、项目配置确定，不使用单一固定超时值覆盖所有消息。

**设计检查点**：
- 区分消息响应超时、PLC 链路断开、桩端主动停止与车端主动停止，分别定义错误码及恢复路径。
- 在应用状态机中显式定义超时事件；取消过期定时器，避免迟到响应触发非法状态迁移。
- 高压安全动作由明确的整车控制责任方执行；EVCC 应按接口契约及时上报并确认安全状态。
- HIL 至少覆盖：无响应、延迟响应、重复响应、通信重连、充电中断与正常退出。

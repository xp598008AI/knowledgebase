# 技术图片与图解资产库

本目录统一归档跨文档复用的技术图片、流程图、系统架构图、状态机、时序图和动画关键帧。分类和命名规则见 [技术图片资产规范](../00-index/技术图片资产规范.md)。

## 分类

- `electrical/`：电气基础、保护、接地、绝缘
- `power-electronics/`：功率拓扑、器件工作原理、损耗和控制
- `embedded-software/`：软件架构、驱动、RTOS、状态机
- `charging/`：充电系统、EVCC、OBC、DCDC、BMS、充电桩
- `safety-process/`：ASPICE、功能安全、FMEA、验证流程
- `frontier/`：储能、AIDC、SST

## 新增图片流程

1. 将图片和可编辑源文件放入合适的子目录。
2. 新建或更新同目录说明文件，记录来源、版本、审核状态和技术要点。
3. 从相关知识文档使用相对路径引用图片。
4. 更新 `00-index/INDEX.md`，验证图片路径和显示效果。

图片是证据/解释的载体，不替代标准原文、设计计算或验证记录。

## 对充电产品的映射

- OBC：PFC塑形输入电流；隔离DC/DC适配电池电压与隔离要求。
- 高低压DCDC：关注电压范围、电流应力、隔离、效率与动态响应。
- 充电桩功率模块：将拓扑、控制、热、并联均流与系统保护联合考虑。
- EVCC：协议协调与功率控制分工明确；功率级快速保护由相应电源控制与硬件承担。

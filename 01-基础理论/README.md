# 01-基础理论

基础理论总入口：硬件、电气、电力电子、数学、控制理论、嵌入式及可复用的工程基础。

## 子主题

详见本目录下的子目录。新建内容建议使用 [技术知识卡片模板](../templates/技术知识卡片模板.md)，并记录来源、版本和审核状态。

## 建议学习路径
1. 电路基础与RLC → MOSFET及驱动 → ADC/滤波与采样。
2. Buck/Boost → PFC/LLC/DAB → 损耗、热设计与保护。
3. 控制理论与环路补偿 → MCU/RTOS实现 → 仿真和验证。

## 学习方式
每个专题先看知识地图，再看[高效技术学习卡片](../templates/高效技术学习卡片模板.md)，最后用[工程专题模板](../templates/工程专题深度文档模板.md)复盘。新增资料应记录来源、版本和验证状态。

# 知识库回收站

删除的资料先移入此目录，便于查阅和恢复。

## 删除与恢复规则

1. 默认“删除”表示移入回收站；保留原文件内容、文件名及相对目录结构。
2. 每次操作建立独立批次：`回收站/YYYY-MM-DD_序号/原路径`，日期按北京时间，同日序号递增，避免覆盖已有批次。
3. 文档及其专属图片、附件一并移动；跨主题共享资源仅在明确授权时移动。检查原位置的索引与引用，必要时更新。
4. 每个批次附带清单，记录时间、原因、原路径、文件数、来源提交和恢复方法。
5. 恢复时按原路径移动回去；遇到同名文件先比较，不能直接覆盖。
6. 仅在用户明确要求“永久删除”或“清空回收站”时移除回收站文件；此操作不会抹除 Git 历史。

这是一套仓库操作规范，并非拦截 GitHub 网页或其他客户端删除操作的自动机制。执行删除的工具或人员需要遵循此规则。

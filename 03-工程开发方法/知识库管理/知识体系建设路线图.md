# 知识体系建设路线图
> 版本：v1.0｜日期：2026-10-13｜状态：规划稿（待逐项核验）

## 建设目标
以六大领域为分类主轴，以“知识地图→速学卡片→工程专题→验证证据→复习”为学习主线。每个知识点只维护一个主文档，其余位置用相对链接引用。保留现有文件，不做破坏性迁移。

## 六大知识树
| 领域 | 二级方向 | 关键知识点 |
|---|---|---|
| 01 基础理论 | 电路与器件；电力电子；控制理论；嵌入式；工程数学 | MOSFET、RLC、运放、ADC；Buck/Boost/PFC/LLC/DAB；PID与环路；MCU/RTOS/通信 |
| 02 市场与产品定义 | 市场；需求；竞品；产品决策 | 场景、需求分解、竞品参数、成本与商业风险 |
| 03 工程开发方法 | ASPICE；IPD；功能安全；FMEA；AUTOSAR；项目管理 | 需求追溯、SYS/SWE、HARA、ASIL、失效链、RTE/BSW |
| 04 充电系统与产品 | EVCC/SECC；协议；OBC；DCDC；BMS；充电桩；无线充电 | CP/PP、PLC、DIN 70121、ISO 15118、功率变换、状态机 |
| 05 验证与质量管理 | 软件测试；SIL/HIL；DV/PV；EMC；可靠性；失效分析 | 测试设计、故障注入、覆盖、边界、8D、FTA |
| 06 创新、扩展与职业竞争 | 专利；储能；AIDC；SST；技术情报；职业成长 | 技术路线、专利挖掘、商业化与能力发展 |

## 重点学习路径
1. **EVCC**：CP/PP与PLC → IEC 61851及DIN/ISO 15118 → 协议状态机 → 诊断/超时 → HIL与互操作。
2. **ASPICE**：过程概览 → SYS.2/3 → SWE.1/2/3 → SWE.4/5/6 → SUP与MAN → 端到端证据链。
3. **电力电子**：器件 → 拓扑 → 损耗/热 → 控制环路 → 仿真 → DV/PV。
4. **功能安全**：危害场景 → HARA → 安全目标 → FSC/TSC → 安全机制 → 验证确认。

## 跨领域示范：EVCC通信超时
- 基础理论：时钟、计时器、任务调度。
- 工程开发：需求、软件架构、可追溯性。
- 产品实现：请求响应、超时事件、状态转换。
- 验证质量：故障注入、边界、迟到报文。
- 注意：超时数值必须依据具体协议版本、消息及设计需求，不得将演示值当作标准值。

## 文档分层
- **知识地图**：主题全貌、依赖、学习顺序、导航。
- **速学卡片**：一句话、图、机制、参数、示例、失效、自测。
- **工程专题**：需求/架构/设计/计算/异常/验证/复盘。

## 目录治理
- 现有六大目录保留，原文件暂不移动。
- 06中的储能/AIDC/SST与“前沿技术”存在双入口时，确定单一主文档，其他仅链接；迁移前核对引用。
- 主题图放文档旁images/，跨主题资产按现有图片资产规范管理。
- 标注来源、版本、适用范围、审核状态；AI生成内容不得冒充实测或标准原文。
- 新增主题时先检查重复、建立主文档，再从上级README建立导航。

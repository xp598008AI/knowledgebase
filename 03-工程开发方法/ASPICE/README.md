## 实践路线

1. 先确认项目采用的 PAM/PRM 版本、客户要求和评估范围。
2. 建立过程适用性矩阵、项目计划、角色责任和风险清单。
3. 选一个真实功能打通需求 → 架构/设计 → 实现 → 测试 → 缺陷/变更的双向追溯。
4. 使用追溯矩阵模板和评审检查表，确保每份证据关联准确版本。
5. 通过 QA、配置管理、问题解决和变更控制保持证据一致、可复现、可审查。
6. 将 AI 生成内容作为学习草稿，经过标准版本核对和工程审核后再纳入项目受控过程。

> 指南、模板和图示属于学习/实践参考，不是 Automotive SPICE PAM 官方流程图或标准原文。具体过程编号、名称、过程属性、工作产品及能力等级要求，以项目采用的正式模型和评估范围为准。

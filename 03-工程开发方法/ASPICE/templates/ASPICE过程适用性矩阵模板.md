## 3. 裁剪决策规则

1. 不得仅因“当前没有文档”就判定过程不适用。
2. 每个排除或部分适用的决定都应有可追溯的理由、批准人和日期。
3. 检查外包/供应商交付、接口责任和客户提供工作产品，避免边界遗漏。
4. 识别项目与组织过程、功能安全、网络安全、法规及客户流程的接口。
5. 发生范围、架构、供应链或生命周期变更时，重新评估适用性。
6. 适用性矩阵必须与项目计划、责任矩阵、工作产品清单及评估范围保持一致。

## 4. 评审检查项

- [ ] 使用的模型/版本已由项目确认。
- [ ] 评估范围与客户/组织要求一致。
- [ ] 所有纳入范围的过程均有责任人和实施安排。
- [ ] 所有不适用/部分适用的结论均有批准依据。
- [ ] 外部接口和供应商工作产品已覆盖。
- [ ] 与项目计划、风险清单和交付物清单一致。
- [ ] 变更触发条件和重新评审责任人已定义。
